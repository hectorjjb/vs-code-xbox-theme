# Theme samples

Short, syntactically rich code samples used to capture marketplace screenshots
across all three Xbox themes (XBOX 360, XBOX ONE, XBOX Series X).

Each file is intentionally small (≈40–80 lines) and exercises a representative
mix of keywords, strings, numbers, comments, types, decorators, and operators
so theme regressions are easy to spot side-by-side.

| File | Language | Notable scopes |
|---|---|---|
| `sample.ts` | TypeScript | generics, decorators, async/await, template literals, JSX-free |
| `sample.tsx` | React + TS | JSX, hooks, prop types, conditional rendering |
| `sample.py` | Python | f-strings, type hints, decorators, dataclasses, docstrings |
| `sample.cs` | C# | records, pattern matching, LINQ, async, attributes |
| `sample.go` | Go | structs, interfaces, goroutines, error handling |
| `sample.rs` | Rust | traits, lifetimes, generics, macros, derive |
| `sample.java` | Java | records, sealed types, lambdas, streams |
| `sample.html` | HTML | semantic tags, attributes, embedded script/style |
| `sample.css` | CSS | custom properties, nesting, media queries, gradients |
| `sample.json` | JSON | nested objects, arrays, primitives |
| `sample.yaml` | YAML | anchors, lists, multi-line strings, comments |
| `sample.md` | Markdown | headings, code fences, tables, links |
| `sample.sh` | Bash | heredocs, conditionals, pipes, variable expansion |
| `sample.sql` | SQL | DDL, joins, CTEs, window functions |
